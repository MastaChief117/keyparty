# KeyParty — Upcoming Features

## Quick Wins (1-2 hours each)
- [ ] Request replay with diff — replay a failed request and show before/after response
- [ ] Provider response time leaderboard — track and rank average latency per provider
- [ ] Monthly cost report — auto-generated PDF/email summary of spending
- [ ] Model cost calculator — paste a prompt, estimate cost across all providers
- [ ] Custom guardrail regex — user-defined patterns to block/flag

## Medium Effort (half day each)
- [ ] MCP support — let tools like Claude Desktop connect via Model Context Protocol
- [ ] Prompt marketplace — save, share, and rate community prompt templates
- [ ] Multi-user auth — separate logins with per-user usage tracking
- [ ] Request queue with priorities — VIP requests jump the queue
- [ ] Semantic request search — "find me all requests about Python debugging"

## Big Brain Features (full day+)
- [ ] Provider speed tests — automated benchmarking across all providers, update smart router
- [ ] Agent mode — gateway can use tools (web search, code execution) via function calling
- [ ] Federated gateway — multiple KeyParty instances share keys and sync state
- [ ] Real-time cost dashboard — WebSocket-powered live spending feed
- [ ] Plugin system — let users write custom middleware in Go or WASM

## Chaos Features (because why not)
- [ ] AI debate club — 3+ providers argue a topic, judge picks the winner
- [ ] Provider tier list — auto-generate rankings based on your actual usage
- [ ] Code review mode — send a PR diff to multiple providers, compare reviews
- [ ] Roast my code — paste code, get roasted by the angriest provider
