Chat Completions (OpenAI-Compatible)

This is the main endpoint. Your apps talk to this.

MethodPOST
Endpoint/v1/chat/completions
AuthUnified API key via Authorization: Bearer <key>

Request Body

FieldTypeRequiredDescription
modelstringyesModel name. Format: provider/model or just model (auto-routed)
messagesarrayyesArray of message objects [{"role":"user","content":"hello"}]
temperaturenumberno0.0-2.0 (default: varies by provider)
max_tokensintegernoMax output tokens
streambooleannoEnable SSE streaming
top_pnumbernoNucleus sampling

Request Headers

HeaderRequiredDescription
AuthorizationyesBearer YOUR_UNIFIED_KEY
Content-Typeyesapplication/json
X-Gateway-ProvidernoForce a specific provider (e.g. groq)
X-Gateway-ModelnoOverride the model name (e.g. llama-3.3-70b-versatile)

Response

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "model": "groq/llama-3.3-70b-versatile",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Hello!"},
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 3,
    "total_tokens": 15
  }
}

Streaming Response

When "stream": true, returns SSE events:

data: {"choices":[{"delta":{"content":"Hello"},"index":0}]}

data: {"choices":[{"delta":{"content":"!"},"index":0}]}

data: [DONE]

Virtual Keys

Create API keys for friends/users without sharing your real provider keys.

Create Virtual Key

MethodPOST
Endpoint/admin/virtual-keys
AuthAuthorization: Bearer <admin-password>
{
  "name": "friend-key",
  "monthly_budget": 5.00,
  "rate_limit": 10,
  "allowed_models": "groq/llama-3.3-70b-versatile,gemini/gemini-2.5-flash"
}

Returns the virtual key: vk-xxxxxxxx. Use it exactly like a unified key.

List Virtual Keys

GET /admin/virtual-keys

Delete Virtual Key

DELETE /admin/virtual-keys/:id

Provider Override

Force a specific provider and model via headers — no code changes needed.

curl http://localhost:8080/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "X-Gateway-Provider: gemini" \
  -H "X-Gateway-Model: gemini-2.5-flash" \
  -d '{"model":"anything","messages":[...]}'
Note: The model field in the request body is ignored when the header is present. The header always wins.
