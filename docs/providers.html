Provider Details

Groq

Free Tier 1000 RPD

  • Fastest inference available (Groq LPU hardware)
  • 12K tokens per minute on free tier
  • Best for: speed-sensitive apps, prototyping, cost-free experimentation
  • Quota resets at midnight UTC daily
  • Auto-failover to Gemini on 429/402

Gemini (Google)

Free Tier

  • Generous free tier with good rate limits
  • Best for: failover target, long context, multimodal
  • Uses alt=sse endpoint for streaming
  • Excellent as compact/backup provider

OpenAI

Paid Only

  • GPT-4o, GPT-4o-mini, GPT-4.1, o1, o3
  • Best for: highest quality responses, complex reasoning
  • Most expensive option

Anthropic

Paid Only

  • Claude Opus 4, Sonnet 4, Haiku
  • Best for: long-form content, analysis, coding
  • 200K context window on Claude models

NVIDIA

Free Tier

  • Nemotron models on NVIDIA API
  • Good for: experimentation, NIM platform

xAI (Grok)

Paid Only

  • Grok models from xAI
  • Best for: real-time information, conversational AI

Mistral

Free Tier

  • Mistral Large, Small, Codestral
  • Best for: European data residency, multilingual

DeepSeek

Free Tier

  • DeepSeek V3, R1
  • Best for: reasoning, math, code generation

OpenAI-HK

Free Tier

  • OpenAI-compatible proxy with free tier
  • Good for: prototyping when OpenAI quota is exhausted

Custom Provider

Add any OpenAI-compatible API:

{
  "name": "my-company",
  "base_url": "https://api.my-company.com/v1",
  "api_key": "sk-xxxx",
  "model": "my-model-name"
}

Just needs to support the OpenAI /v1/chat/completions format.

Adding a Provider Key

Via dashboard or API:

curl -X POST http://localhost:8080/admin/api-keys \
  -H "Authorization: Bearer your-admin-password" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-groq-key",
    "provider": "groq",
    "key": "gsk_xxxxxxxxxxxx",
    "model": "llama-3.3-70b-versatile"
  }'
Model mapping: When you specify a model, KeyParty maps it to the correct provider endpoint automatically. If you omit the model, the provider's default model is used.

Provider Token Budgets

Set monthly token and cost caps per provider:

curl -X POST http://localhost:8080/admin/provider-budgets \
  -H "Authorization: Bearer your-admin-password" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "groq",
    "monthly_token_budget": 1000000,
    "monthly_cost_budget": 0.00
  }'

Once the budget is hit, requests to that provider are rejected with 402. Failover kicks in if enabled.
