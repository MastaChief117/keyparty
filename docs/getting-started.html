Getting Started

From zero to "holy crap my $4 of API keys actually works" in 5 minutes.

What is KeyParty?

KeyParty is a single-binary AI gateway. You give it your API keys from 10+ providers (OpenAI, Anthropic, Gemini, Groq, NVIDIA, etc.), and it gives you one endpoint to rule them all. Your apps talk to KeyParty, KeyParty talks to the providers. If one provider dies, it fails over to another. Your users never see the 429.

Prerequisites

  • Go 1.24+ installed (go version to check)
  • At least one API key from a provider (Groq, Gemini, and NVIDIA have free tiers)
  • A terminal (you know how to use one, right?)

Step 1: Install

Clone the repo

git clone https://github.com/MastaChief117/keyparty.git
cd keyparty

Build it

go build -o keyparty .

Takes about 10 seconds. Produces a ~16MB binary. No Docker. No npm. No node_modules. Just vibes.

Run it

./keyparty -port 8080 -admin-pass your-password

You'll see:

KeyParty running on http://localhost:8080
Proxy endpoint: http://localhost:8080/v1/chat/completions
Dashboard: http://localhost:8080
Admin auth: enabled

Step 2: Open the Dashboard

Go to http://localhost:8080 in your browser. You'll see the dashboard. The first thing you'll notice is your Unified API Key — that's the key you'll use in your apps.

Pro tip: Copy that unified key and save it somewhere. You'll need it in Step 4.

Step 3: Add Your API Keys

Get an API key from a provider

Start with one of the free-tier providers:

  • Groq — console.groq.com — 1000 req/day free, blazing fast
  • Gemini — aistudio.google.com — generous free tier
  • NVIDIA — build.nvidia.com — free tier available

Add it to KeyParty

In the dashboard, go to API Keys tab → click + Add Key.

  • Key Name: anything you want (e.g. "my-groq-key")
  • Provider: select your provider
  • Key: paste your API key
  • Model: leave blank for default, or pick a specific model

Test it

Click the Test button next to your key. You should see a green "Key works!" message.

Step 4: Send Your First Request

Open a terminal and send a request through the gateway:

curl http://localhost:8080/v1/chat/completions \
  -H "Authorization: Bearer YOUR_UNIFIED_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "groq/llama-3.3-70b-versatile",
    "messages": [{"role": "user", "content": "say hello in 3 words"}]
  }'

You should get a response back from Groq, routed through KeyParty. Congrats, you're an AI gateway now.

That's it. You now have a multi-provider AI gateway running on your machine. But there's more cool stuff you can do.

Step 5: Use It in Your App

Point your OpenAI-compatible client at the gateway:

Python (OpenAI SDK)

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="YOUR_UNIFIED_KEY"
)

response = client.chat.completions.create(
    model="groq/llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "hello"}]
)
print(response.choices[0].message.content)

JavaScript (fetch)

const response = await fetch("http://localhost:8080/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_UNIFIED_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "groq/llama-3.3-70b-versatile",
    messages: [{ role: "user", content: "hello" }]
  })
});
const data = await response.json();
console.log(data.choices[0].message.content);

Go

req, _ := http.NewRequest("POST", "http://localhost:8080/v1/chat/completions", body)
req.Header.Set("Authorization", "Bearer YOUR_UNIFIED_KEY")
req.Header.Set("Content-Type", "application/json")

resp, _ := http.DefaultClient.Do(req)
// read response...

Step 6: Add More Providers

The magic of KeyParty is having fallbacks. Add more keys:

  1. Get keys from 2-3 providers (Groq + Gemini + NVIDIA is a great free combo)
  2. Add them all to the dashboard
  3. Send requests — KeyParty routes them automatically

Step 7: Set Up Failover

If one provider dies, KeyParty can automatically reroute to another. In the dashboard, go to Failover tab:

  1. Enable failover
  2. Set backup provider (e.g. gemini)
  3. Set backup model (e.g. gemini-2.5-flash)
  4. Enable auto-compact (summarizes chat history on failover)

Now when Groq rate-limits you at 3am, your users won't notice. You'll sleep like a baby.

Step 9: Virtual Keys

Want to share access with friends without giving them your real API keys? Create virtual keys:

curl -X POST http://localhost:8080/admin/virtual-keys \
  -H "Authorization: Bearer your-admin-password" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "friend-key",
    "monthly_budget": 5.00,
    "rate_limit": 10,
    "allowed_models": "groq/llama-3.3-70b-versatile,gemini/gemini-2.5-flash"
  }'

They get a vk- key. Use it exactly like the unified key. Budget enforced. Rate limited. Your wallet stays safe.

Step 10: Provider Override Headers

Want to force a specific provider without changing your code? Use headers:

curl http://localhost:8080/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "X-Gateway-Provider: gemini" \
  -H "X-Gateway-Model: gemini-2.5-flash" \
  -d '{"model":"anything","messages":[...]}'

The model field in the body doesn't matter — the header wins. Great for A/B testing or debugging.
